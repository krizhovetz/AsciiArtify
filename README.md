# AsciiArtify

AsciiArtify — стартап, що розробляє продукт для перетворення зображень у ASCII-art за допомогою Machine Learning.

## Документація

- [doc/Concept.md](doc/Concept.md) — Concept проєкту: порівняльний аналіз minikube, kind та k3d для локального Kubernetes-середовища розробки, оцінка ризиків ліцензування Docker, розгляд Podman як альтернативи, демо та рекомендації.
